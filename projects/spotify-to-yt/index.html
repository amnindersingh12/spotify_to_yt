Spotify to YouTube

Sync Spotify music into YouTube

This is the dedicated project page for your Spotify-to-YouTube app. The UI is the polished desktop app in the repo, and this page is the project entry point on your VM. If you want the browser to directly control the sync flow, the next step is to wrap the Python logic in a web backend; this page is already set up for that upgrade.

Projects Home Open Live App

What this app does

  • Connects Spotify and YouTube accounts.
  • Reads liked songs or a specific Spotify playlist.
  • Creates a new YouTube playlist and syncs matches into it.
  • Shows progress, status, and sync results in the app UI.
